# City MMO — Debug 第 1 輪（繁體中文）

## 檢查結果

- `npm test`：世界規則、存檔測試、登入 token 測試通過。
- JavaScript 語法檢查：`server/`、`shared/`、`assets/js/`、`assets/shared/`、`tools/` 全數通過。

## 本輪修正

1. **修正 Socket.IO 登入驗證漏洞**：原先只要送出任意字串 token，後端就可能建立玩家。現在必須先找到該 token 對應的已註冊帳號，否則拒絕連線初始化。
2. **修正玩家名稱可信來源**：玩家名稱以已註冊帳號資料為準，不再信任客戶端傳入的名稱。
3. **修正未登入連線可訂閱地圖區塊的問題**：`viewport` 事件現在要求先完成登入初始化。
4. **修正舊／失效 token 導致登入畫面卡住**：驗證失敗時清除本機登入狀態並重新顯示登入表單。
5. **處理特殊帳號鍵名**：帳號表改為無原型字典，避免 `__proto__` 等特殊鍵名被 JavaScript 物件原型影響。

## 測試範圍與限制

本次已執行世界規則測試、存檔測試、登入 token 輔助函式測試與所有 JavaScript 檔案的語法檢查。完整 HTTP + Socket.IO 瀏覽器端到端測試尚未執行；部署後仍應用兩個不同瀏覽器測試註冊、登入、建造、聊天及重新啟動後的存檔。
