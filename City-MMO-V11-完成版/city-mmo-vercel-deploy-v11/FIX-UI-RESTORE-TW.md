# City MMO CDE 修復版：恢復建築選單與按鈕

## 這次故障原因

上一版只更新了伺服器載入的 `shared/buildings.js`，卻沒有同步更新瀏覽器實際載入的 `assets/shared/buildings.js`。`index.html` 使用後者。於是前端讀不到 `GameData.GAME_MODES`，在建立建築選單時發生 JavaScript 例外，導致建築類別／新建築／裝飾選項沒有被建立，之後部分按鈕事件也尚未綁定。

## 修復內容

- 同步 `shared/buildings.js` 到 `assets/shared/buildings.js`，確保瀏覽器和伺服器看到相同的建築定義與遊戲模式。
- 前端加上 `GAME_MODES` 相容備援，避免舊快取或版本混用時整個遊戲 UI 因此停止初始化。
- 前端資源網址加入版本查詢參數，減少瀏覽器持續使用舊 JavaScript 的機會。
- 新增回歸測試，會比對前端與後端建築目錄、遊戲模式是否一致，防止同樣問題再次發生。

## 更新方式

1. 先備份目前整個遊戲資料夾與存檔。
2. 解壓縮此修復 ZIP 到新的資料夾檢查內容。
3. 將新版專案檔案更新到你原本的專案；不要刪除原本存檔資料，也不要建立會重設世界的 `RESET_WORLD_ONCE` 檔案。
4. 重新啟動 Node.js 伺服器／重新發布靜態前端。
5. 瀏覽器強制重新整理：Windows/Linux 按 `Ctrl + Shift + R`，macOS 按 `Cmd + Shift + R`。
6. 進入遊戲後確認「交通、能源水利、住宅、商業、工業、公共服務」原始分類仍在，並另有「新建築」「城市裝飾」分頁。

## 測試範圍

已執行 `npm test`、所有專案 JavaScript 的 `node --check` 語法檢查，以及前後端建築目錄同步測試。這些不是代替真實部署後的多人瀏覽器測試；部署更新後仍需實際確認登入、建造與多人同步。
