    City MMO 已放上 GitHub Pages

    這裡是遊戲前端，但多人遊戲伺服器尚未設定。

    GitHub Pages 只會託管 HTML、CSS 與 JavaScript，不能執行 Node.js 伺服器。因此登入、城市同步、聊天、交通資料與結盟功能，需要先把伺服器部署到支援 Node.js／WebSocket 的主機。

    部署完成後，編輯 assets/js/config.js，把 window.GAME_SERVER 設成你的伺服器 HTTPS 網址，再重新上傳。

    詳細步驟請看專案中的 README-GITHUB-TW.md。
